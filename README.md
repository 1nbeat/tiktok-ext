# 抖音视频下载助手

本项目能帮助你批量下载你喜欢、收藏的抖音作品，同时也提供指定作品解析下载功能。

项目通过 Chrome DevTools Protocol（CDP）连接已经登录抖音的 Chrome 页面，在页面上下文中调用抖音接口，同步“喜欢”和“收藏”列表。同步结果展示在本地 Web 页面中，可以查看作品详情、播放视频、切换清晰度、浏览图集，也可以批量下载全部喜欢作品。

## 功能概览

- 同步抖音个人页中的喜欢和收藏作品。
- 支持视频和图集识别。
- 支持标题、作者搜索和多种排序方式。
- 支持分页浏览，减少大量作品同时渲染造成的卡顿。
- 点击作品卡片打开本地详情弹窗，不跳转抖音页面。
- 详情弹窗展示作者、互动数据、发布时间、音乐、标签、位置和技术信息。
- 点击作者名称，在新浏览器标签页打开抖音用户主页。
- 视频支持实时播放、循环播放、拖动进度和清晰度切换。
- 图集支持逐张浏览、键盘切换、图片放大、滚轮缩放和拖动查看。
- 图集作品的配乐通过独立音频流播放，并自动循环。
- 支持输入指定作品链接，解析后复用现有详情弹窗进行播放和下载。
- 支持批量下载全部喜欢作品。
- 批量下载支持视频和图集，图集会保存到独立文件夹。
- 批量下载支持 1 至 10 个并发 worker，可实时查看实际并发数、文件大小、下载速度和进度。
- 支持暂停、继续、取消、失败项重试和已存在文件跳过。
- 视频和图片均通过本地媒体代理访问，减少抖音 CDN 的跨域和来源校验问题。

## 工作原理

程序由本地 Node 服务、浏览器控制连接和前端页面三部分组成：

```text
已登录的 Chrome
        │ Chrome DevTools Protocol
        ▼
    server.mjs
        │ HTTP API / 本地媒体代理 / 下载 worker
        ▼
  public/index.html + app.js + styles.css
        │
        ├── 同步作品列表
        ├── 获取详情和播放地址
        └── 创建并监控下载任务
```

### 同步流程

1. `start.bat` 启动带调试端口的独立 Chrome 用户目录，并打开抖音个人页。
2. 用户在该 Chrome 窗口中登录抖音。
3. 前端调用 `POST /api/sync/start`。
4. Node 服务通过 CDP 找到抖音页面，在页面上下文中请求喜欢和收藏接口。
5. 如果接口分页失败，页面脚本会回退到滚动虚拟列表的方式收集作品。
6. 服务端将抖音原始数据转换为统一的作品结构，返回给前端展示。

程序本身不读取或保存 Cookie。登录态由 Chrome 保存到项目目录下的 `.chrome-debug-profile`，后续启动会复用该浏览器用户目录。

### 详情和播放流程

点击作品后，前端调用 `GET /api/video?id=作品ID` 获取最新详情。服务端优先复用已登录的抖音个人页请求详情，失败时会打开独立的后台标签页作为回退路径。

详情中的视频、音乐和图片地址会登记到内存白名单，并通过 `GET /api/video/stream` 由 Node 转发。媒体地址只短期有效，过期后需要重新打开作品获取新地址。

### 批量下载流程

批量下载任务在服务端后台运行，前端只负责创建任务和轮询状态。每个 worker 独立领取一个待处理作品，因此单个大文件不会阻塞其他下载 worker。

- 默认并发数：2。
- 最大并发数：10。
- 失败重试次数：3 次。
- 默认跳过已经存在且大小大于 0 的文件。
- 视频保存为 `douyin-作品ID.mp4`。
- 图集保存到 `douyin-作品ID/`，图片按 `001.jpg`、`002.jpg` 的顺序命名。
- 未完成文件先保存为 `.part`，支持下次继续下载。
- 任务状态写入 `download-state.json`，服务重启后正在下载的任务会恢复为暂停状态。

## 项目结构

```text
tiktok-ext/
├── public/
│   ├── app.js              # 前端状态、渲染、弹窗、播放和下载交互
│   ├── index.html          # 页面骨架和所有 UI 容器
│   ├── styles.css          # 页面、详情弹窗、图集和下载面板样式
│   └── favicon.svg         # 网站图标
├── server.mjs              # Node 服务、CDP、同步、详情、代理和下载任务
├── start.bat               # Windows 一键启动脚本
├── package.json            # 项目元数据和启动命令
├── .gitignore              # 本地配置、下载文件和运行时文件忽略规则
├── downloads/               # 下载文件目录，运行时自动创建，不提交 Git
├── download-state.json      # 下载任务状态，运行时生成，不提交 Git
└── .chrome-debug-profile/   # 独立 Chrome 用户目录，包含登录状态，不提交 Git
```

### `server.mjs` 主要职责

- 启动本地 HTTP 服务，默认监听 `5173`。
- 连接 Chrome 的 `9222` 调试端口。
- 注入页面脚本并同步喜欢、收藏列表。
- 规范化作品、作者、互动数据、音乐和媒体地址。
- 获取指定作品和列表作品的实时详情。
- 校验并代理抖音视频、音乐和图片 CDN 请求。
- 创建、持久化和执行批量下载任务。
- 管理下载并发、断点续传、重试、暂停和取消。

### `public/app.js` 主要职责

- 保存喜欢、收藏、搜索、排序和分页状态。
- 渲染作品卡片和分页控件。
- 管理作品详情弹窗和图集放大层。
- 播放视频、图集配乐并切换清晰度。
- 创建指定下载和批量下载任务。
- 轮询同步状态、下载状态和当前活动文件进度。

## 环境要求

- Windows。
- Google Chrome。
- Node.js 22 或更高版本。
- 抖音账号，并能够在 Chrome 中正常登录。

项目只使用 Node.js 内置模块，不需要安装第三方 npm 依赖。

## 启动方式

### 推荐方式：一键启动

双击项目目录中的 `start.bat`。脚本会依次完成：

1. 检查 Chrome 和 Node.js 是否安装。
2. 检查 `9222` 调试端口是否已经可用。
3. 如果端口不可用，启动独立 Chrome 用户目录并打开抖音个人页。
4. 启动 Node 服务。
5. 打开 `http://localhost:5173`。

首次启动时，在新打开的 Chrome 窗口中完成登录。之后可以直接再次运行 `start.bat`，登录态会从 `.chrome-debug-profile` 自动恢复。

### 手动启动

如果不使用 `start.bat`，需要先以调试模式启动 Chrome：

```bat
chrome.exe --remote-debugging-port=9222 --user-data-dir="D:\code\tiktok-ext\.chrome-debug-profile" "https://www.douyin.com/user/self"
```

然后在项目目录执行：

```bash
npm start
```

最后访问：

```text
http://localhost:5173
```

服务只绑定本机使用，不建议将 `5173` 或 `9222` 暴露到公网或局域网。

## 使用说明

### 同步作品

1. 确认 Chrome 已打开抖音个人页并已登录。
2. 打开本地页面，点击“从抖音同步”。
3. 等待同步完成，页面会显示喜欢和收藏数量。
4. 使用搜索、排序、分页浏览作品。

同步结果只保存在服务进程内存中。Node 服务重启后，作品列表需要重新同步。

### 查看和播放作品

点击任意作品卡片即可打开详情弹窗。视频会自动请求最新播放地址并循环播放；如果接口返回多个码率，可以在“清晰度”下拉框中切换。图集会显示单张图片，左右按钮或键盘方向键可以切换图片。

### 下载指定作品

点击“下载指定”，粘贴作品原网页地址后点击“解析并打开”。程序不会先校验固定域名或固定路径，而是尝试从输入内容中解析作品 ID；无法解析时会在弹窗中提示错误。解析成功后会打开现有详情弹窗，可直接播放、切换清晰度和下载。

### 批量下载

1. 在页面顶部选择清晰度和并发数。
2. 点击“下载全部作品”。
3. 确认弹窗会显示视频数量、图集数量、清晰度和并发数。
4. 点击“开始下载”。
5. 下载面板会显示总体进度、实际并发数以及当前文件的大小、速度和进度。

下载过程中可以暂停、继续或取消。任务完成后可以关闭进度面板；关闭只隐藏页面显示，不删除任务记录或已下载文件。

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/sync/start` | 后台开始同步喜欢和收藏列表 |
| `GET` | `/api/sync/status` | 查询同步进度和最新同步结果 |
| `GET` | `/api/sync` | 获取最近一次同步数据 |
| `POST` | `/api/download/jobs` | 创建批量下载任务 |
| `GET` | `/api/download/jobs` | 获取最近的下载任务列表 |
| `GET` | `/api/download/jobs/:id` | 获取指定任务详情和活动文件进度 |
| `POST` | `/api/download/jobs/:id/pause` | 暂停任务 |
| `POST` | `/api/download/jobs/:id/resume` | 继续任务 |
| `POST` | `/api/download/jobs/:id/cancel` | 取消任务 |
| `POST` | `/api/download/jobs/:id/retry-failed` | 重试失败项 |
| `GET` / `HEAD` | `/api/video/stream` | 代理视频、音乐或图片媒体流 |
| `GET` | `/api/video?id=:id` | 获取作品最新详情 |

批量下载创建请求示例：

```json
{
  "quality": "highest",
  "concurrency": 5,
  "skipExisting": true
}
```

其中 `quality` 支持 `highest` 和 `standard`，`concurrency` 会被服务端限制在 1 至 10 之间。

## 数据、隐私和安全

- 服务默认只监听本机地址，页面地址为 `http://localhost:5173`。
- Chrome 调试端口为 `9222`，请不要对外暴露。
- `.chrome-debug-profile` 可能包含 Cookie、登录态和浏览历史，必须保持在本地并避免提交到 GitHub。
- `downloads/` 可能包含大量视频和图片，已加入 `.gitignore`。
- `download-state.json` 可能包含作品标题、作者和下载路径，已加入 `.gitignore`。
- Node 服务不会主动把 Cookie 写入文件，也不会上传同步结果到第三方服务器。
- 抖音播放地址通常具有时效性，失效后重新打开作品即可刷新。

## 常见问题

### 页面提示找不到 Chrome 调试页面

确认 Chrome 是由 `start.bat` 启动，或者手动启动时确实带有 `--remote-debugging-port=9222`。同时检查 Chrome 中已经打开抖音个人页，而不是普通新标签页。

### 同步数量少于抖音页面显示数量

抖音页面使用虚拟列表，页面显示数量和接口返回数量可能存在差异。项目会优先使用分页接口，并在接口失败时滚动页面兜底；重复作品会按作品 ID 去重。建议等待同步完全结束后再比较数量。

### 视频或图集无法播放

播放地址可能已经过期，关闭详情弹窗后重新打开作品。如果仍然失败，确认 Chrome 登录状态有效，并检查抖音页面是否能正常播放该作品。

### 服务重启后下载任务没有继续

这是预期行为。服务重启时，正在下载的任务会恢复为暂停状态，已完成文件不会丢失。在下载面板中点击“继续”即可恢复剩余项目。
